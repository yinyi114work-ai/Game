# 個管手速王 V3.4｜每次操作有意義

針對 V3.3 回饋修改：
- 照顧計畫由 5 次點擊改為 2 次：「確認需求與服務」→「完成計畫送審」。
- 開額度由 3 次點擊改為 2 次：「核對剩餘額度」→「確認開立」。
- 每次有效點擊都會在物件上方出現醒目的 PERFECT 或 GOOD 動畫，並顯示實際工作動作。
- 首次點擊重視及時反應；後續點擊重視節奏，不用刻意拖延到逾時。
- 保留 60 秒、電話黑洞、工作互斥、3 秒倒數、MISS、Burnout、結算。

## 使用
完整解壓縮，維持 `index.html`、`style.css`、`js/game.js` 目錄關係。此為測試版，請先不要覆蓋正式網站。
