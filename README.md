# 個管手速王 V3.5｜韓系漫畫動畫美術版

以 V3.4 遊戲邏輯為基礎，保留 60 秒、事件生成、兩步照顧計畫／開額度、PERFECT/GOOD、電話黑洞、工作互斥、MISS、Burnout、結算統計。

## 本次美術更新
- 全面更新暖粉、奶油色韓系漫畫配色、面板、辦公室裝潢、物件質感與按鈕。
- 場景、角色與六種工作物件仍為獨立 DOM/CSS 圖層，不是單張圖片。
- 新增窗邊光點、頭髮擺動、人物工作反應、電話震動、LINE 震動、異常事件跳動、家訪包擺動、操作符號氣泡。
- 保留原有遊戲機制與分數判定。

## 使用方式
解壓縮後，保持 `index.html`、`style.css`、`js/game.js` 的相對位置，將全部檔案上傳到 GitHub Pages 儲存庫根目錄。GitHub 不會自動解壓縮 ZIP。

## 測試狀態
已進行 JS 語法檢查與 Chromium 桌面無頭瀏覽器截圖／點擊冒煙測試；iPhone Safari 尚未實測。這是美術迭代版，不是完成的逐格角色動畫或商用級手繪美術。
