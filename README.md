# 個管手速王 V3.2｜可達成完美通關的平衡版

這版調整遊戲難度，不再讓事件生成量超過玩家理論上能處理的上限。

- 事件生成間隔：0–15秒 3.0–3.8秒；15–30秒 2.3–3.0秒；30–45秒 1.8–2.4秒；45–54秒 1.4–1.9秒。
- 最後 6 秒不再產生新工作，讓玩家有收尾機會。
- 每種工作最多同時排隊 2 件；總生成上限 27 件（包含開場兩件）。
- 延長工作期限，保留最後 3 秒倒數和 MISS。
- 電話黑洞機率從 43% 降到 26%，持續時間約 4.5–6 秒。
- 電訪中僅能處理 LINE、開額度，且不能出發家訪。
- 目標：熟練玩家有機會達成零 MISS、零未完成；5% 為設計目標，尚未經玩家實測驗證。

保留 index.html、style.css、js/game.js 的目錄結構上傳 GitHub Pages。
