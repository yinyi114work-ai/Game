# 個管手速王 V3.7｜難度調整＋電話掛斷倒數

以 V3.6 為基礎，保留既有韓系 2D 畫面、操作評價、六項任務、電話互斥、MISS、Burnout、結算。

- 通話時在場景上方常駐顯示「電話黑洞／電訪中｜N 秒後可掛斷」。
- 可掛斷時，同一區塊變成醒目的綠色「掛斷電話！點這裡結束通話」，點擊可立即掛斷；電話物件同步閃爍。
- 提高事件生成頻率、事件上限到 39 件；最後 6 秒停止生成，保留收尾空間。
- 各工作期限略縮短，壓力累積加快；仍保留最後 3 秒倒數。
- 保留每次有效操作 PERFECT／GOOD 的評價。

本版是針對玩家回饋調整的候選測試版。尚未經 iPhone Safari 實機測試或統計 Perfect 通關率。

部署：解壓縮後，保持 index.html、style.css、js/game.js 相對路徑。
