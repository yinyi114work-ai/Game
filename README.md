# 個管手速王 V3.3 — 操作評價版

## 玩法變更
- 每次有效點擊都有工作動作名稱、GOOD 或 PERFECT，以及操作加分。
- 接聽電話重視即時反應，異常事件重視及時處理，其他工作以合理操作節奏判定。
- 不需等待 PERFECT 時機才可以操作，任何時候都能正常推進工作。
- 結算新增單次 PERFECT / GOOD 次數。零 MISS、零未完成且至少 60% 有效操作 PERFECT，判定 PERFECT CLEAR。
- 沿用 60 秒、最後 3 秒警示、電話黑洞、工作互斥、Burnout。
- 事件上限 27、最後 6 秒不生成，保留全清空的可能。

此版本未經實際玩家數據校準，5% 完美通關率仍是目標而非實測結果。請在測試站驗證後再部署正式網站。
