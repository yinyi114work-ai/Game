# 個管手速王 V3.1｜2D 動畫強化測試版

這是獨立測試版，不會修改既有 GitHub Pages 網站。

## 專案結構
- `index.html`：入口
- `style.css`：人物、辦公室、物件動畫與手機版面
- `js/game.js`：60 秒遊戲、工作生成、電話黑洞、互斥、MISS、結算、音效

## 本次改進
- 針對手機直式畫面改為滿版自適應，減少左右黑邊
- 待辦越多，桌上文件越堆越高；連續完成顯示 COMBO
- 新增可開關的合成音效（不需要下載音訊檔）
- 通話中不再生成新的電話任務，避免不合理的重複來電
- 電訪期間只能處理 LINE 和開額度；家訪中無法處理任何工作
- 保留 60 秒、後 30 秒加速、3 秒倒數、MISS、Burnout 和結算

## 使用
將所有檔案保留原有目錄結構。GitHub Pages 直接部署根目錄即可。手機端音效需在玩家按下開始後才可播放。

## 限制
仍是以 CSS 圖層及程式動畫製作的 2D 原型，尚非逐格繪製的精緻角色動畫。尚未完成 iPhone Safari 實機測試。
