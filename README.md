# 個管手速王 V3 — 動畫遊戲測試版

這是獨立的多檔案 2D 動畫原型，並非最終美術版。不需要安裝任何套件，也不會自動變更現有 GitHub Pages。

## 試玩
開啟 `index.html` 即可。部署時將 `index.html`、`style.css`、`js/game.js` 保持原有相對路徑，一起放在 GitHub Pages 的發布目錄。

## 規則
60 秒；後 30 秒加速。六種工作以各自期限排隊，最後 3 秒倒數，逾時 MISS。電話接聽後隨機延長，需再次點擊掛斷；通話中只能回 LINE 與開額度。家訪 3.1 秒無法操作。結束統計完成、MISS、未完成。壓力 100% 提前 Burnout。

## 限制
使用 CSS 圖層與動畫繪製人物與物件，尚未使用正式逐格動畫美術。此版重點在動態、互斥與觸控玩法。桌面 Chromium 只做基礎渲染與腳本測試，尚未實機驗證 iPhone Safari。
